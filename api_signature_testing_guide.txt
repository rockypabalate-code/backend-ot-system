REQUIRED TEST ORDER
===================

1. Admin uploads signatures for the Employee and Supervisor.
2. Employee OT Plan is submitted_to_supervisor.
3. Employee signs, or Supervisor signs on behalf.
4. Supervisor accepts the Employee OT Plan.
5. Supervisor creates the Department OT Plan.
6. Supervisor starts the Department approval route.
7. Assigned preliminary approvers approve.
8. Admin completes final approval.
9. Admin lists approved Department OT Plans.
10. Admin manually generates the final Excel for the selected plan.
11. Authorized user retrieves the Excel signed URL.


1. ADMIN UPLOADS EMPLOYEE SIGNATURE
===================================

Endpoint:
  POST /api/users/signature

Auth:
  Required admin token

Postman body type:
  form-data

Request body structure:

{
  "userId": "user-1784594747663",
  "signature": "<File: C:\\Users\\SCAN\\.codex\\generated_images\\019fa205-ba87-7a81-8eb7-7cfbe8455aae\\exec-b4eaeae1-db6b-475d-89da-deb0a416ccf6.png>"
}

In Postman, configure the fields as:
  userId     Text    user-1784594747663
  signature  File    Select the TEST ONLY PNG

Do not send this request as raw JSON. The curly-brace object above only shows
the complete form-data input structure.

Success response:

{
  "message": "Signature saved for the target user successfully.",
  "signature": {
    "signatureId": "SIGNATURE-...",
    "userId": "user-1784594747663",
    "uploadedBy": "user-1783921262438",
    "signatureFilePath": "users/user-1784594747663/....png",
    "mimeType": "image/png",
    "status": "active",
    "signedUrl": "https://...",
    "expiresInSeconds": 300
  }
}

COMMON ERROR RESPONSES
======================

No saved signature:

{
  "message": "No saved signature was found.",
  "code": "SIGNATURE_NOT_FOUND"
}

Missing admin upload target userId:

{
  "message": "Target user ID is required in the userId form-data field.",
  "code": "SIGNATURE_USER_ID_REQUIRED"
}

Target user does not exist:

{
  "message": "Target user not found.",
  "code": "SIGNATURE_USER_NOT_FOUND"
}

Employee or approver has no signature:

{
  "message": "Save a signature before approving this Department OT Plan.",
  "code": "SIGNATURE_REQUIRED"
}

Employee Plan is not ready to sign:

{
  "message": "The employee overtime plan must be submitted to the supervisor before it can be signed.",
  "code": "PLAN_NOT_READY_FOR_SIGNATURE"
}

Supervisor accepts an unsigned Employee Plan:

{
  "message": "Every employee in the overtime plan must confirm or be confirmed by the assigned supervisor before acceptance.",
  "code": "EMPLOYEE_SIGNATURE_REQUIRED"
}

Final Excel requested before final approval:

{
  "message": "The Department OT Plan must be fully approved before generating its final document.",
  "code": "PLAN_NOT_APPROVED"
}

Final document is not ready:

{
  "message": "The final Excel document is not ready.",
  "code": "FINAL_DOCUMENT_NOT_READY"
}

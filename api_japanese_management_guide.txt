IMPORTANT JAPANESE MANAGEMENT ACCOUNT RULES
============================================

The Japanese Management role is:
  japanese_management

The account must have users.status equal to active.

Japanese Management does not need an employee profile to use its approval and
view-only endpoints.

Before approving a Department OT Plan, the account must have a saved signature.
Only Admin can upload or replace that signature.

Japanese Management can approve only an approval assignment linked to its exact
user ID. With two Japanese Management approvers, each account receives and acts
on its own pending approval record.

Japanese Management is a preliminary approver. Supervisor and all assigned
Japanese Management approvals must be completed before HR/Admin final approval.

JAPANESE MANAGEMENT SETUP WORKFLOW
==================================

1. Admin creates the Japanese Management account.

Endpoint:
  POST /api/admin/users

Auth:
  Required Admin token

Request body:
  {
    "firstName": "Kenji",
    "middleName": "",
    "lastName": "Sato",
    "email": "kenji.sato@example.com",
    "password": "JapaneseManager@123",
    "role": "japanese_management",
    "status": "active"
  }

2. Admin uploads the Japanese Management signature.

Endpoint:
  POST /api/users/signature

Auth:
  Required Admin token

Postman body type:
  form-data

Fields:
  userId      Text  <japanese-management-user-id>
  signature   File  <PNG or JPEG signature image>

3. Admin or HR assigns the user to an approval route.

The route can contain two Japanese Management users:
  {
    "departmentId": "DEP-PRODUCTION-RTD",
    "routeName": "Production RTD OT Approval Route",
    "status": "active",
    "supervisorApproverUserId": "user-supervisor-001",
    "japaneseManagementApproverUserIds": [
      "user-japanese-management-001",
      "user-japanese-management-002"
    ]
  }

4. Log in using the Japanese Management account.

  APPROVAL_ALREADY_PROCESSED

      "planId": "DEPTPLAN-...",

          "status": "rejected",

          "remarks": "Please correct the employee hours and submit the plan again."

    }

Important:
  Remarks are required.
  Returning the plan marks the acting approval rejected and skips the remaining
  pending approval records for that submission attempt.

Common errors:
  REJECTION_REMARKS_REQUIRED
  NOT_ASSIGNED_APPROVER
  PLAN_NOT_PENDING_APPROVAL

RECOMMENDED JAPANESE MANAGEMENT TESTING FLOW
============================================

1. Admin creates an active japanese_management account.
2. Admin uploads its signature with POST /api/users/signature.
3. Admin or HR includes the user ID in an active department approval route.
4. Japanese Management logs in with POST /api/auth/login.
